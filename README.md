# We Create Tomorrow

Karaoke app — School of Economics · Cần Thơ University. Hai ca khúc: "Chúng ta cùng đi"
(tiếng Việt) và "We Create Tomorrow" (tiếng Anh).

Đây là **bản build tĩnh** (production build), dùng để lưu trữ trên GitHub Pages. Không phải
kho mã nguồn phát triển.

Trang chạy tại: xem mục **About** của repo hoặc tab **Deployments** sau khi GitHub Actions
build xong.
